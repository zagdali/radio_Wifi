# ESP32 Internet Radio

Проект `internetRadio2` для ESP32-S3 с веб-интерфейсом, OLED-дисплеем и I2S-выходом на PCM5102.

## О проекте

- ESP32-S3 DevKitC-1 именно (esp32-s3-devkitc-1-n16r8)
- Веб-интерфейс на `data/index.html`
- Управление станциями и звуком через REST API
- OLED-дисплей выводит состояние и название станции
- PCM5102 принимает I2S и выводит аналоговый звук

## Сборка и загрузка

1. Открой рабочую папку проекта в VS Code.
2. Установи PlatformIO и нужные библиотеки.
3. Собери проект командой:

```bash
pio run -e esp32-s3-devkitc-1
```

4. Запиши прошивку на плату:

```bash
pio run -e esp32-s3-devkitc-1 -t upload
```

5. Загрузите файловую систему (если используешь LittleFS):

```bash
pio run -e esp32-s3-devkitc-1 -t uploadfs
```

## Подключение OLED-дисплея

В проекте OLED подключён по I2C и использует следующие пины ESP32-S3:

- `GPIO8` — `SDA`
- `GPIO9` — `SCL`
- `3.3V` — `VCC` (или `5V`, если модуль поддерживает питание 5V)
- `GND` — земля

Адрес OLED: `0x3C`.

> В `src/main.cpp` используется `U8G2_SSD1306_128X64_NONAME_F_HW_I2C`.

## Подключение PCM5102

На твоей плате PCM5102 пины обычно подписаны так:

1. `G` — земля
2. `MCLK` — мастер-клок / BCLK
3. `LR` — левый/правый канал (LRCK / WS)
4. `SD` или `5D` — цифровой аудиосигнал (DATA)
5. `3V3` — питание 3.3V

В проекте используются такие пины ESP32-S3:

- `GPIO4` → `MCLK` (BCLK)
- `GPIO5` → `LR` (LRCK / WS)
- `GPIO6` → `SD` / `5D` (DATA)
- `GND` → `G`
- `3V3` → `3V3`

> Важно: подключай PCM5102 к `3.3V`, если на плате подписано `3V3`. Не подавай `5V` на этот контакт.

### Пример схемы подключения

```
ESP32-S3      PCM5102
GND       ->  G
GPIO4     ->  MCLK
GPIO5     ->  LR
GPIO6     ->  SD / 5D
3V3       ->  3V3
```

### Рекомендации по питанию

- Если модуль обозначен `3V3`, подключай только `3.3V`.
- Всегда подключай общую землю между ESP32, OLED и PCM5102.

```
ESP32-S3   OLED
GPIO8  ->  SDA
GPIO9  ->  SCL
GND    ->  GND
3.3V/5V ->  VCC
```

## Примечания

- Убедись, что I2S-пины на твоём ESP32-S3 не заняты другими функциями.
- Если OLED не отображается, проверь адрес и питание.
- Если нет звука, проверь питание PCM5102 и общий GND.

## Порядок запуска

1. Включи ESP32-S3.
2. Подключись к Wi-Fi или точке доступа.
3. Открой веб-интерфейс и выбери станцию.
4. На PCM5102 должны появиться аналоговые L/R сигналы.
